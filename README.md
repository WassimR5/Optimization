Combinatorial Optimization TP: Knapsack & TSP
This repository contains Object-Oriented Programming (OOP) solutions for two classic optimization problems: the 0/1 Knapsack Problem and the Traveling Salesman Problem (TSP). Developed as part of my Master’s degree in AI & Informatics.

🚀 Overview
The project implements various metaheuristic strategies to solve NP-hard problems, focusing on the trade-off between execution speed and solution quality.

Algorithms Implemented:
Greedy Algorithm: Provides a fast, baseline solution by making locally optimal choices at each step.

Local Search: Iteratively improves the solution by exploring the neighborhood.

Simulated Annealing (SA): A probabilistic technique that avoids local optima by occasionally accepting "worse" solutions based on a cooling schedule.

🏗️ Architecture (OOP Design)
The project is designed using clean, modular principles to ensure readability and maintainability:

Problem Models: Clear separation between Knapsack and TSP data structures.

Strategy Pattern: Algorithms are decoupled from the problem instances, allowing for easy testing of different parameters.

Result Helpers: Standardized output for performance metrics and solution details.
